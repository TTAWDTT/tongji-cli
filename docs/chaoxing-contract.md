# 学习通接口约定

本模块遵循仓库现有适配方式，不引入独立客户端框架：命令在 cli.py 注册，认证交给 auth.py，学习通请求和解析集中在 chaoxing.py，汇总交给 schedule.py，终端显示交给 display.py。

## 对齐依据

- canvas/api.py 的 request：验证来源、HTTP 状态和响应类型，再解析数据。
- media/courses.py 的 courses/course_page：标识、页面结构、空结果和列表完整性需要明确证据，不能把解析失败当成零项。
- common.py 的 QueryUnavailable/failure 与 display.py：使用既有状态和错误出口；聚合失败时保留成功来源。

## 输入和请求

省略 `--course` 查询当前机构目录中可核实的课程。传入的选择条件须非空且唯一。优先匹配 `课程ID:班级ID`，其次是课程编号或全名，最后是名称包含匹配。目录有未读页或坏条目时，只有已列出的复合 ID 能用于精确选择。机构标识必须可确定，同一复合 ID 的课程入口参数发生冲突时，该班级记入错误。

请求使用 GET，单次超时 20 秒，每条跳转链最多六次请求。课程和详情按顺序读取，整个查询的耗时随可见课程和作业数增长。每一跳校验超星子域、HTTPS 默认端口和当前操作允许的只读路径。HTTP 入口升级为 HTTPS。详情仅跟随已识别的作业入口、预览和查看页。链接中出现的作业、课程、班级标识须与所选记录一致。

响应须为 HTML 或 XHTML。相对详情地址以作业目录最后一次响应的 URL 为基准，保留百分号编码。跳转、成功和失败响应的缓冲区都会释放。错误说明只包含可展示的失败原因。

## 输出和失败

课程使用 `id/title`。作业使用 `id/title/course/submitted/due/source`，附带班级、官方状态和时间原文。明确提交与未交分别对应 `true` 和 `false`，缺失、未知或互相矛盾的状态对应 `null`。

截止时间取自列表的时间字段或详情页的作业信息栏。`due_as_listed` 保留原文，包括“待定”等表述。`due` 仅在官方证据足以确定年月日和时间时输出上海时区 ISO 时间。详情给出完整时间时采用详情值，详情只给月日和时间时可保留列表中与它相符的完整时间。同一信息栏的截止字段冲突、简写与列表不符或缺少年份依据时，返回 `null`。

正常空结果须有对应目录的明确空提示。权限提示、隐藏模板、无法识别的页面均不足以证明目录为空。发现可用“下一页”时，返回已读页和范围说明。坏条目、重复标识或单门课失败时，继续读取其余可核实条目。

`partial` 的 `items` 只含已核实条目，`errors` 记录对应范围。`courses_checked` 是尝试查询的班级数。详情读取失败时保留已知的列表字段和链接，并标记 `detail_status=unverified`。部分结果返回非零退出码。

`login/status/today/week` 默认查询 Canvas 和教务。学习通单独认证，通过 `--include-chaoxing` 加入日程。`today` 的 `chaoxing.items` 仅含当天截止项，日期未知项在 `chaoxing.undated_assignments`。`week` 按日列出 `chaoxing_assignments`，日期未知项在 `week.undated_assignments`。学习通读取不完整时，仅在有已核实截止项的日期给出每日字段。完整结果中的空列表表示该日已知截止项为零。

## 维护与验证

维护时先确认官方页面结构，再修改本模块；复用已有 QueryUnavailable 和显示机制。新增布局须同时提供脱敏样例及覆盖其失败边界的测试，不把个人课程 HTML、登录资料或带签名的真实作业 URL 提交进 Git。

测试至少覆盖响应类型、超时、站外跳转、无年份日期、无效日期、课程歧义、标识错误、跨班链接、分页信号、详情失败保留列表和部分成功汇总。网页变动可能要求重新适配；离线测试不能替代真实登录、目录、作业和周汇总验证。

专项测试通过 `python -m unittest discover -s tests -p 'test_chaoxing*.py'` 运行。浏览器测试使用临时会话，HTTP 异常、权限、分页和时间冲突由合成响应提供。
